# Popi Pastel Theme

Un tema fosc amb tons pastel dissenyat per a reduir la fatiga visual i mantindre una estètica elegant en llargues sessions de programació.

## 🚀 Instal·lació

1. Obri Visual Studio Code.
2. Ves a la vista d'Extensions (`Ctrl+Shift+X` en Windows/Linux, `Cmd+Shift+X` en macOS).
3. Busca **Popi Pastel Theme**.
4. Fes clic en **Instal·lar**.
5. Prem `Ctrl+K Ctrl+T` (`Cmd+K Cmd+T` en macOS) i selecciona el tema.

## ✨ Característiques

- Fons fosc profund que ressalta la sintaxi sense enlluernar.
- Paleta de colors pastel acuradament seleccionada (rosa, malva, cian suau).
- Alt contrast en els elements de la interfície (terminal, explorador d'arxius).
